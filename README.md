1. Clone Project về
2. Sau khi clone về sau đó bật terminal lên và gõ lệnh các lệnh sau để khởi tạo server
- **cd Sever**
- **node server.js**
3. Mở ứng dụng Android Studio
- Chọn File > Open, trỏ đến thư mục **TaskProject01** và bấm OK
- Verification: Android Studio tiến hành Gradle Sync thành công, hiển thị đầy đủ cấu trúc cây thư mục và có thể bấm nút Run (▶) để chạy lên máy ảo hoặc thiết bị thật.
